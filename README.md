# Blog Refletindo sobre o Caminho

Reflexões de Milton Jordão sobre a Palavra e a caminhada da fé.

- Os textos ficam em `src/posts/` (um arquivo por texto).
- As imagens de capa ficam em `src/imagens/`.
- Para escrever e publicar textos sem mexer em código, use o painel em https://app.pagescms.org (entrar com a conta do GitHub).
- O site é publicado automaticamente pelo Netlify a cada alteração.
